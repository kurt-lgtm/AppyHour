HOW TO USE MATRIX COMMANDER

  1. Set the cohort — Ship Day (SAT = main Saturday cohort, TUE = Dallas-only) and Ship Date, top right.
  2. Get orders in — either way:
    • Generate from Shopify: enter the RMFG tag (e.g. RMFG_20260706) and click the button. Pulls live orders and builds the matrix directly — replaces the RMFG portal export.
    • Drop an xlsx: drag the RMFG xlsx (plus optional gift xlsx) onto the drop zones, then Validate Upload.
  3. Read the QC checks — validation runs 7 checks: order IDs, zip leading-zeroes, duplicate columns, production day, SKU mappings, MFG onboarding, and the CEX-EC chain (a bare CEX-EC with no CEX-EC-suffix line, or a suffix whose expected cheese is missing, gets flagged). Fix reds before going on.
  4. Inventory cross-check — Load from Settings (canonical %APPDATA% settings) or upload an inventory CSV. Shortages appear per SKU.
  5. Swap resolution — resolve each shortage; each decision is applied to the xlsx.
  6. Finalize XLSX — merges the gift sheet (if any) and writes the final matrix file.
  7. Sync to Shopify — disabled in the web UI (it bypassed the pipeline guardrails). Use the CLI: python matrix_commander.py sync-shopify (dry-run by default).

Rules of the road live in AppyHour/MATRIX_RULES.md — read it before changing anything. Canonical CLI export: matrix_commander.py generate via gen_rmfg_export.py (QC-gated).
